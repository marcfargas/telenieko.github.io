Odoo Toolbox

Odoo ERP integration for AI agents
1 min · Marc Fargas EN
Table of Contents
  • What It Does
  • Quick Start

AI-friendly Odoo integration — progressive knowledge modules and TypeScript client for working with Odoo v17 ERP.

What It Does#

Teaches AI agents how to work with Odoo through progressive, CI-tested skill modules. Instead of dumping 12,000 pages of Odoo docs into context, agents load only what they need: connection → domains → CRUD → domain-specific (mail, accounting, timesheets).

Every code example in the skills is extracted and tested against a real Odoo v17 instance in CI. No doc rot, no hallucinated APIs.

Quick Start#

Install (updated 2026-02-15)

npx skills add marcfargas/odoo-toolbox

TypeScript packages:

npm install @marcfargas/odoo-client
npm install @marcfargas/odoo-introspection

Scaffold a skill project:

npx @marcfargas/create-odoo-skills my-odoo-skills

What’s Inside#

  • 8 foundational skills: connection, domains, field types, CRUD, search, introspection, properties, modules
  • 5 domain-specific skills: mail/chatter, accounting, contracts, attendance, timesheets
  • TypeScript client: Lightweight RPC client (@marcfargas/odoo-client)
  • Schema introspection: Discover models/fields dynamically (@marcfargas/odoo-introspection)
  • All skills CC0 (public domain) — code is LGPL-3.0

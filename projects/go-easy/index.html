Go Easy

Google APIs for AI agents
1 min · Marc Fargas EN
Table of Contents
  • What It Does
  • Quick Start
  • What’s Inside

Unified TypeScript library and CLIs for Gmail, Drive, Calendar, and Tasks — designed for AI agents.

What It Does#

Wraps Google’s official APIs in a single library with four agent-friendly CLIs:

  • go-gmail: Read, search, send email; manage drafts; handle threads
  • go-drive: Upload, download, search files; manage folders
  • go-calendar: Create events, manage calendars, query availability
  • go-tasks: Create, update, list tasks across task lists

Two-phase OAuth works in headless environments (auth in browser, token to server). Pagination, encoding quirks, and token refresh handled transparently.

Quick Start#

Install (updated 2026-02-15)

npx skills add marcfargas/go-easy

Install CLIs:

npm install -g @marcfargas/go-easy

TypeScript library:

npm install @marcfargas/go-easy

First-time auth (interactive):

npx go-gmail auth

Then agents can call:

npx go-gmail search "from:john subject:invoice"
npx go-drive upload report.pdf --folder-id <id>
npx go-calendar create "Team sync" --start "2026-02-20T10:00:00"
npx go-tasks create "Review proposal" --list-id <id>

What’s Inside#

  • 4 gateway CLIs: go-gmail, go-drive, go-calendar, go-tasks
  • TypeScript library: @marcfargas/go-easy (also exports programmatic API)
  • pi skill: Teaches agents the CLI patterns, auth flow, common operations
  • Skills CC0 (public domain) — code is MIT
